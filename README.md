# 向日葵保卫战

一款以向日葵为主题的植物大战僵尸式单机塔防游戏。纯原生 HTML + CSS + JavaScript + Canvas 实现，**不使用任何游戏引擎，不需要联网，不需要安装任何依赖**。

## 怎么开始玩

直接双击 `index.html`，用浏览器（Chrome / Edge / Firefox 均可）打开即可游玩。

## 玩法

枯萎的向日葵变成了小僵尸，正朝小院走来。种下向日葵伙伴，收集阳光，守住三波来袭！

- **5 行 × 9 列草坪**：把上方的植物卡牌**拖到空地上**松手即种（键盘玩家：数字键选卡 + 方向键选格 + 回车种植）。
- **合体进化（可到 3 级）**：把草坪上一株植物拖到另一株上，或把上方卡牌**直接拖到已种好的植物上**（照常消耗该卡阳光）。**1级＋1级＝2 级**：相同种类进化为更强形态（金星徽章：双管射手连发两颗瓜子、暖阳葵每 6 秒产 +50 大太阳、铁壳葵血量翻倍、烈日葵爆炸范围大增）；**不同种类合出混血大植物**，同时拥有两种本领——暖阳葵＋瓜子射手＝又产阳光又射击，冰露葵＋铁壳葵＝会减速弹的肉盾……**2级＋1级＝3 级**（两颗金星，不需要两株 2 级）：三管射手连发三颗瓜子、暖阳葵每 4.5 秒产 +75 大太阳、铁壳葵血量三倍、烈日葵爆炸范围更大；血量为参与合体的植物血量之和。混血植物左肩会开出副本领的小花作为标记。
- **难度滑动条**：顶部"僵尸强度"滑动条可把僵尸血量在 ×0.5 ～ ×5 之间调节，对之后出场的僵尸生效（设置自动保存）。
- **无敌模式**：顶部"无敌模式"按钮需输入密码开启，开启后阳光无限、卡牌无冷却、植物不受伤害；再点一次关闭。
- **阳光**：点击或拖动从天上掉落、暖阳葵产出的太阳，每个 +25 阳光。
- **铲除**：点铲子（或按 `S`）再点植物移除（不返还阳光），**一铲一除**，铲完自动放回铲子。
- **葵花小推车**：僵尸走到最左边时，该行小推车会自动清场一次——每行只有一次机会，之后僵尸再越过就输了。

### 植物伙伴（数字键 1–6 快速选择）

| 植物 | 阳光 | 作用 |
| --- | --- | --- |
| 暖阳葵 | 50 | 每 12 秒产出一个太阳 |
| 瓜子射手 | 100 | 向本行发射瓜子，持续攻击 |
| 冰露葵 | 150 | 发射冰瓜子，伤害略低但让僵尸减速 |
| 铁壳葵 | 75 | 高血量肉盾，替后排挡伤害 |
| 烈日葵 | 125 | 种下后短暂蓄力，对附近三行僵尸爆炸 |
| 翠玉瓜葵 | 150 | 抛出西瓜沿抛物线砸向僵尸，落点范围内群体伤害 |

### 葵花僵尸

- **枯萎葵尸**：最普通的敌人
- **领队葵尸**：扛着小旗冲在每波最前面，更快更结实
- **葵盆头**：头顶花盆，更结实
- **瓜子桶**：满桶瓜子护甲，血量很高
- **疾跑小葵尸**：小个子，跑得飞快
- **大块头葵尸**：体型巨大，血厚伤害高，走得慢
- **超级巨大葵尸**：双头巨兽，血极厚、一口重咬，走得最慢——波次后段的 boss
- **气球葵尸**：吊着气球从植物头顶飘过——不啃植物、免疫瓜子子弹，**只有翠玉瓜葵抛出的西瓜和烈日葵的地爆能把它打下来**；小推车是最后防线（无尽模式第 5 波起登场）

### 关卡

共 3 关（晨光小院 → 午后葵田 → 落日守望），每关 3 波，越往后僵尸越多、种类越杂、来得越密。另有**无尽葵田**和**无尽·肉鸽**（两者随时可选，无需通关）：僵尸潮一波接一波、越来越强，看你最多能守多少波（最佳纪录自动保存）。每行小推车**全场只能救援一次**（无尽模式也不重置）。进度保存在浏览器本地。每关每一波有哪些僵尸、各多少只，全部在 `waves.js` 里显式配置，改起来一目了然。

**无尽·肉鸽（传送带模式）**：植物栏换成一条从右往左滑动的传送带，随机植物卡免费送来（瓜子射手、冰露葵、铁壳葵、烈日葵、翠玉瓜葵，不出暖阳葵——这个模式没有阳光经济；烈日葵和铁壳葵刷得最多，西瓜最少）；拖到草坪上直接种，拖到植物上免费合体。卡槽共 7 格，挤满后最左边的卡会掉下去，且波数越深传送越快（开局 7 秒一张）——手快有，手慢无。僵尸潮与无尽模式相同，但**血量全部翻倍**。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `1` – `6` | 选择植物卡 |
| `S` | 选择 / 取消铲除 |
| `C` | 收集一个太阳 |
| 方向键 + 回车 | 键盘选格种植（无需鼠标） |
| `空格` | 暂停 / 继续 |
| `Esc` | 取消当前选择 / 关闭暂停 |
| 鼠标右键 | 取消当前选择 |

切后台不会自动暂停——游戏只会按你手动点的「暂停」停下来，后台回来也不会跳时间（每帧间隔有钳制）。

## 文件说明

- `index.html` — 游戏入口页面
- `waves.js` — 波次配置：每一关每一波的僵尸种类与数量
- `style.css` — 界面样式（响应式，支持手机触屏）
- `game.js` — 纯游戏规则逻辑（无 DOM 依赖，可单独测试）
- `app.js` — Canvas 绘制、音效与浏览器交互
- `test.js` — 核心规则自动化测试（需要 Node.js，运行 `node test.js`）

所有画面均由代码实时绘制，音效由 Web Audio 本地合成，零外部资源、零网络请求。
